# Triage labels

| Matt Pocock role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and unblocked for autonomous work |
| `ready-for-human` | `ready-for-human` | Founder credentials, authority, or judgment required |
| `wontfix` | `wontfix` | Intentionally not actioned |

Only one triage-role label should normally be active on an issue.
